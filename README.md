# Resumax

Resumax is an AI-powered resume analysis and improvement platform designed for students and freshers.

## Core Features

- AI-powered resume analysis
- ATS readiness evaluation
- Resume improvement recommendations
- Job description matching
- Resume analysis history

## Technology Stack

### Frontend

- React
- TypeScript
- Vite
- SCSS

### Backend

- Python
- FastAPI
- SQLAlchemy
- Pydantic

### Database

- PostgreSQL

### AI

- Ollama (local development)
- Hosted LLM provider (production)

## Project Structure

- `frontend/` - React application
- `backend/` - FastAPI application
- `docs/` - Project documentation

## Project Status

Currently under development.
